# 📰 News Headlines Scraper

A beginner-friendly Python web scraping project that extracts top headlines from Hacker News and stores them in CSV format.

---

## 🚀 Features
- Scrapes live headlines
- Saves data to CSV
- Clean project structure
- Beginner friendly

---

## 🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
